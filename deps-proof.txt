== 3. no package manifest declaring dependencies ===============

== 6. external programs kap runs (disclosed, not linked) =======

kap is a task runner: running your build tool is the product, not a
hidden dependency. None of these is linked, and each degrades with a
message rather than a crash. Full disclosure in STDLIB.md.

  build tools : whatever a plugin declares (cmake, cargo, npm, go, ...)
  curl OR wget: only for "kap plugin install" over the network
  git         : only for installing a plugin from a git URL
  sh          : only to run a user-configured hook string

kap builds, tests, detects, and dry-runs with none of them installed.
